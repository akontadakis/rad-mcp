# Changelog

## 0.1.0 — 2026-10-26

First public release.

- 21 MCP tools covering project setup, geometry import and octree validation, materials with provenance,
  sensor grids, weather, BSDFs, window groups, point-in-time and annual simulation (2-, 3- and 5-phase),
  LM-83 and EN 17037 compliance, renders, image post-processing, DGP and UGR glare, IES luminaires,
  EN 12464-1 uniformity, EN 17037 view out and sunlight exposure, and reproducible script export.
- Two Claude Code skills: `radiance-simulation-workflow` and `lighting-standards-compliance`.
- Claude Code plugin and marketplace manifest for a two-line install.
